# @beskid/spec-core

Structured platform-spec workspace schemas, validation, MDX emit/import, and React Grid Layout contracts for Beskid spec tooling.

## Workspace layout

```
spec.json                 # Node type + widget registry
platform-spec/            # Content root
  compiler/
    node.json
    layout.json
    content.json
.spec/templates/          # Saved layout templates
```

Default origin: `https://spec.beskid-lang.org`
